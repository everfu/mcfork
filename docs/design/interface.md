# 界面设计依据

参考：https://open.mcd.cn/，于 2026 年 10 月 17 日查看实际页面。采用官网的深蓝底色、金黄色主按钮、白色内容区和苹方字体；保持 McFork 自己的名称与图标。工具页使用紧凑标题区，不引入官网的宣传插画与合作入口。

设计令牌：深蓝 `#0d1528`、金黄 `#ffbc0d`、白色 `#ffffff`、页面底色 `#f5f7fa`、文字 `#222222`、次级文字 `#616974`。面板圆角 12px，输入与按钮圆角 7–8px，主要控件最小高度 44px。仅在弹层使用阴影，不使用玻璃模糊与多色渐变。

结构为页头、标题、选店及预算表单，以及左侧餐单编辑、右侧比较结果两个区域。比较前右侧仅显示一块简洁引导，不预留空方案卡、差异栏或不可用的导出按钮。比较后展示实际得到的方案；没有合适方案时用一条说明解释原因，差异摘要与导出放在结果下方。本轮对比仅在有结果后显示。餐品行只保留图片、名称、价格和锁定状态，使用分隔线代替嵌套卡片。主操作统一使用金黄，次操作使用描边或文字。

继续使用 HeroUI 的下拉框、按钮、输入框与弹窗，保留城市/商圈联动、加载与错误状态、键盘焦点、真实数据来源、核价和导出。页面、弹窗、复制文案和 PNG 不展示比赛推广文字；官方原样声明等提交材料保留在仓库文档中。

桌面左侧固定 360px 编辑区，右侧并排展示方案，下方为差异摘要；中等宽度保留左右分区，方案纵向排列；手机按编辑、方案、摘要的阅读顺序排列。城市、商圈、门店、预算使用同一行基线，查询反馈单独占行，异步加载不移动预算框。核对 1512px、390px 和 320px，以及地图或额外 Key 均不参与当前流程的既有约束。
