# 麦麦平行餐桌 McFork

借助当前 AI 客户端理解用户意图，调用本项目 CLI 完成计算；不要另申请大模型或地图 Key。项目只需要本机 `MCD_MCP_TOKEN`，不用把凭据放入对话或命令参数。

先确认城市、地点关键词和用户选定的真实门店，再查询该门店当前菜单。根据用户表达建立原餐单，确认哪些餐品与数量必须保留，预算单位在输入 JSON 中为整数分。不要把“喜欢”自动解释为允许删除其他餐品。

在项目根目录执行 `npm run --silent fork -- stores 输入.json`、`menu 输入.json`、`detail 输入.json` 或 `compare 输入.json`。参数格式见 [references/input.md](references/input.md)。项目根目录是包含 `package.json` 和 `server/cli.ts` 的 McFork 源码目录；尚未找到项目或依赖未安装时，先定位并按项目 README 设置，不猜测其他目录。

读取 CLI JSON 后，说明原餐单总价、最多两份替代餐单、逐项变化、锁定项保留情况、查询时间和试算/官方核价来源。只有 `verified: true` 才能称“官方核价”。展示实际成功核验的范围，不承诺全菜单最低价；`failedCount` 大于零时说明比较不完整。没有可行替代时解释结果，不编造方案或金额。

用户询问套餐详情时，展示默认搭配；`supportModify: true` 标注“可特调”。首版只支持默认搭配，特调请引导至官方客户端。用户未明确要求时不展开特调列表。

不调用下单、领券、兑换、抽奖等写操作。分享小票时仅使用门店、餐品、金额、替换明细与查询时间，不放 Token、账户信息或后台追踪信息。凭据失效、限流或基准餐单无法核价时停止本次比较，报告具体状态，不用演示结果顶替。
