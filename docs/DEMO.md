# 一分钟演示脚本

0–10 秒：展示「喜欢的那一口，不用让」和当前真实门店，解释“真实门店＋官方核价”。录制样例使用演示试算时，保留醒目演示标识。

选店时展示「城市 → 商圈 → 门店」下拉联动。商圈为内置常用目录，实时门店从麦当劳 MCP 查询，演示只使用杭州武林广场的已采集快照。

10–20 秒：展示原餐单，指出汉堡已锁定，预算为整餐 48 元。价格以实际查询或快照为准，不照抄概念图金额。

20–35 秒：点击比较。先看「少改一项」：汉堡和小食保留，只替换饮品。再看「多省一点」：进一步替换小食。逐项说明变化与整单价差。

35–45 秒：切回原餐单、再采用替代方案，说明“可来回比较，不会直接下单”。

45–55 秒：导出一张对比小票，指出门店、原餐单、新餐单与查询时间，不含账户或凭据。

55–60 秒：展示“只需一个麦当劳 MCP Token”，以及网页＋Skill 共用引擎。不要声称全城最低价或已完成下单。
